The adaptive ladder — four rungs on one sheet

Four rungs of the same screen, side by side, so the whole behaviour reads at a glance: ShramSafal asks only for the smallest missing truth. The more the Main Log already understood, the less this screen has on it. This is mental load going down, drawn rather than described.

The test every rung must pass

“Where is ShramSafal asking me for something I already told it?”

Under every frame there is a line naming exactly what the app already knew and therefore did not ask. That line is the proof — if any rung asks for a plot, a crop, a count or a name the farmer already gave, the rung is wrong no matter how good it looks.

One shell. It only loses content.

Every frame below is the same four-slot screen. The reduction is only legible if the shell is visibly the same screen going quieter — so no rung gets a layout of its own.

Slot A

What it already understood

Stated back as fact. Never as a question.

Slot B

The one question

At most one. Sometimes none at all.

Slot C

The action

The mic, an unavailable mic, or just confirm.

Slot D

हजेरी वही — always live

Identical on all four rungs. Memory is never gated.

The frames read 1 → 4 left to right on a wide screen, and top to bottom on a narrow one. Each frame stays exactly 390 px: on a small phone the row of frames scrolls sideways, the page never does.

What this screen must never do

Check the rule as well as the picture. If any of these appear, the ladder is broken even if the screen looks good.

  • Never the same question at two different rungs. Each rung asks its own question, or asks nothing.
  • Never re-ask a fact a lower rung already has. Rung 3 must not ask about गणेश or रमेश; no rung asks the count, the plot, the crop or the job a second time.
  • Never a generic “tell me about your day” prompt at any rung. The mic here only ever collects the one missing truth.
  • Never four different layouts. The reduction is only readable if it is visibly the same screen losing content — the same four slots on every rung.
  • Never a silently dead mic. Rung 1’s mic is visibly unavailable, with a reason and a way forward — not greyed out in silence, and never the word “permission”: this is a missing fact, not a denied right.
  • Never gate the हजेरी वही. It is live and identical on all four rungs. Gating capture must never gate memory.
  • Never a headcount stepper, plot picker, crop picker, amount, or clock time on any rung — the count came with the log, money lives in the register, and attendance remembers duration, never a start-to-end time.
  • Never show an unknown as zero. The variant’s missing count reads —, never 0.
