What this screen must never do

Check the rule as well as the picture — each line below is a thing the drawing above is deliberately not doing.

  • Never a dead end. The inactive hero must always sit above at least one live door — here, the main log and the register.
  • Never a generic error. No “something went wrong”, no retry banner, no red card, no warning triangle. Nothing failed — the day simply has no headcount yet.
  • Never a disabled हजेरी वही tile. The register is not gated by capture state. If the hero is off and the register is off too, the release is wrong.
  • Never a hidden or greyed register. Hiding the tile in this state is the same defect as disabling it — the past is always readable.
  • Never a hint that the farmer did something wrong. No “you forgot”, no “incomplete”, no scolding tone. The app did not understand a count; that is the app's sentence to carry, not his fault to wear.
  • Never a full-screen takeover that replaces the ledger. The reason is a card on the hub, not a modal, not an interstitial, not a screen the farmer has to dismiss before he can reach हजेरी वही.
  • Never re-ask what he already told it. No plot picker, no crop picker, no headcount field, no name checklist anywhere in this state — including on the no-work route.
  • Never draw an unknown day as –, and never a daily or week total of 0 for a day nobody spoke about. Blank means nobody said; the dash means he did not come.
  • Never invent the Marathi. Every yellow chip above is a real gap waiting on the founder's own words — the layout ships for approval, the copy does not.
